# Warehouse War

A low-poly online arena FPS for Android. Up to 8 players fight a free-for-all on four maps (Warehouse, Desert,
Forest, Snow) — in a private room by 6-digit code, through quick match (PLAY), or offline against 5 bots in Practice.

**Stack:** Unity 6.3 LTS (6000.3.28f1) · URP · Photon Fusion 2.1.4 (Host Mode, host-authoritative) · Input System

## Install on Android phones

1. Copy `WarehouseDuel/Builds/Android/WarehouseWar.apk` to the phone and open it (allow **Install unknown apps**).
2. **PLAY** finds other players online (pick a map or Random); the match starts once two are found.
3. **Online War → Create Room** gives a 6-digit code to share; friends use **Join Room**.
4. **Practice** lets you pick a map and fight 5 bots offline.

All players must run the same APK version.

## Features

- 8 weapons (rifle, SMG, shotgun, pistol, sniper, machine gun, knife, RPG); equip any three in the **Armory**.
- 16 costumes (**Wardrobe**), 24 avatars and 24 banners; locked items are bought in the **Shop** with Stars
  (1 per kill, +5 for finishing 1st, online only).
- Profile, local leaderboard and match history, full-screen settings, haptics, generated audio and effects.

## Project layout

| Folder | Contents |
|---|---|
| `WarehouseDuel/Assets/Scripts/Core` | Constants, settings, bootstrap, shared libraries |
| `.../Scripts/Multiplayer` | Fusion session, room state, room codes, network input |
| `.../Scripts/Match` | Match flow, rules, scoring |
| `.../Scripts/Player`, `Weapons`, `Bots` | Character, camera, visuals, weapons, AI bots |
| `.../Scripts/UI`, `Profile`, `Audio`, `Environment` | Screens and HUD, profile/shop, audio, map components |
| `.../Scripts/Editor` | Generators for every scene, prefab, sound, texture and UI (plus validators, screenshot tool) |
| `WarehouseDuel/Assets/Art`, `Audio`, `Prefabs`, `Scenes`, `Resources` | Generated content |

The Unity project folder keeps its original name (`WarehouseDuel/`) and the Android package id stays
`com.warehouseduelstudio.warehouseduel` so installed copies update in place.

## Rebuilding

Everything (scenes, prefabs, sounds, art) is generated by editor scripts. From the repo root:

```powershell
$U = ".tools\Unity\6000.3.28f1\Editor\Unity.exe"
& $U -batchmode -projectPath WarehouseDuel -executeMethod WarehouseWar.EditorTools.GameBuilder.BuildAllBatch -logFile build.log
& $U -batchmode -nographics -projectPath WarehouseDuel -executeMethod WarehouseWar.EditorTools.GameBuilder.BuildAndroidBatch -logFile android.log
```

In the Unity Editor the same actions are under **Tools → Warehouse War**.
