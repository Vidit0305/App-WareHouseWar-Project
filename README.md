# Warehouse Duel

A low-poly 1v1 online FPS for Android. Two players join a private room by code, choose weapons, and fight a
three-minute deathmatch in an industrial warehouse.

**Stack:** Unity 6.3 LTS (6000.3.28f1) · URP · Photon Fusion 2.1.4 (Host Mode, host-authoritative) · Input System

## Install on Android phones

1. Copy `WarehouseDuel/Builds/Android/WarehouseDuel.apk` to each phone (USB, Google Drive, WhatsApp to yourself…).
2. Open it on the phone and allow **Install unknown apps** when Android asks.
3. Player 1: **Play Online → Create Room**, then share the code (e.g. `K7QPM-E`) with the **Copy** button.
4. Player 2: **Play Online → Join Room**, type the code, **Join**.
5. Both pick a weapon and press **READY**; the host presses **START MATCH**.

Both phones need internet (Wi-Fi or mobile data; different networks are fine).

## Rebuilding

Everything (scenes, prefabs, sounds, art) is generated by editor scripts. From the repo root:

```powershell
$U = ".tools\Unity\6000.3.28f1\Editor\Unity.exe"
& $U -batchmode -projectPath WarehouseDuel -executeMethod WarehouseDuel.EditorTools.GameBuilder.BuildAllBatch -logFile build.log
& $U -batchmode -nographics -projectPath WarehouseDuel -executeMethod WarehouseDuel.EditorTools.GameBuilder.BuildAndroidBatch -logFile android.log
```

In the Unity Editor the same actions are under **Tools → Warehouse Duel**.
